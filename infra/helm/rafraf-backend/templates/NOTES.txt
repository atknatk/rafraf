## Ingress / ALB requirement

ingress.host is REQUIRED when ingress.enabled=true. The chart fails the
render with a helpful message if it is empty — this prevents a silent
ALB Controller misconfiguration where `host: ""` provisions a broken
load balancer. Per-env values files MUST set ingress.host:

  values-staging.yaml -> ingress.host: staging-api.rafraf.app
  values-prod.yaml    -> ingress.host: api.rafraf.app

------------------------------------------------------------------------
## Secret rotation post-deploy

The ExternalSecret refreshes the underlying Kubernetes Secret on the
configured interval ({{ .Values.externalSecrets.refreshInterval }}), but
running pods do NOT restart automatically when the Secret changes.
JWT_PRIVATE_KEY / JWT_PUBLIC_KEY / APNS_KEY / database creds rotated
in AWS Secrets Manager will only take effect after a manual rollout:

  kubectl -n {{ .Release.Namespace }} rollout restart deploy/{{ include "rafraf-backend.fullname" . }}
  kubectl -n {{ .Release.Namespace }} rollout status  deploy/{{ include "rafraf-backend.fullname" . }}
